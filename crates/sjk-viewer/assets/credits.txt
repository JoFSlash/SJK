# the `credits` console command). The file is built into the client
# (include_str!) and parsed once; unit tests in credits_data.rs check it, so
# `cargo test` catches a broken edit. CREDITS.md stays the full written record.
#
# Format, in display order:
#
#   == Section title   Starts a section (a later "== Supporters" needs no code).
#   [Name]             Starts a card in the current section.
#   github: handle     Optional GitHub account, shown as @handle; clicking it
#                      opens https://github.com/handle.
#   role: text         Required: one line under the name.
#   did: text          One contribution per line (repeat the key); optional.
#   link: https://...  A clickable address under the card (repeat the key);
#                      optional, https only. "link: Label | https://..." shows
#                      the label instead of the address.
#   medal: id          A medal from the SJK team, shown on the card with its
#                      picture and name (repeat the key for more); optional.
#                      The ids are the hub's (crates/sjk-viewer/src/medals.rs):
#                      early_tester, early_contributor, bug_hunter.
#                      An unknown id is an error, and so is one listed twice
#                      (no medal is repeatable since 21/10/2026).
#
# Lines starting with '#' and blank lines are ignored. ASCII only: the menu fonts
# draw bytes. Every merge into main that brings someone's work adds it here: a
